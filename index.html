The fonts are drawn on top of each other. Where the outlines match you see one shape. Where they differ, the edges split into Pixel Vector, Pixel Soft, Rounded and Rounded Game (same outlines as Rounded, game spacing). Pick one of the game's other fonts under Font to compare its Pixel Vector and Rounded Game; Pixel Soft and Rounded exist only for Normal.

Metrics
Read from the font files with fontTools (1600 units per em, 100 units per source pixel).

    

    

      

      
    

    
The fonts of one game font share the same vertical metrics, so lines align exactly when stacked. The Rounded font adds 100 units (1 px) to every advance and shifts outlines right by half a pixel, which is why it runs wider in the overlay. Rounded Game uses the same outlines with the game advances, so it overlays the pixel fonts without any correction.
